# 使用说明

与 [../USAGE.md](../USAGE.md) 同步（均为中文）。代码与命令仍为英文。

## 环境

```bash
conda activate torch2.4_cuda12.1   # 实际为 torch 2.6.0+cu124
export PYTHONPATH=/data/WebGAP/src
export HF_ENDPOINT=https://hf-mirror.com
# 权重目录：/data/models/Qwen/Qwen3-VL-8B-Instruct（禁止放进仓库）
```

单卡 A800 80GB。不要下载 WebQA 原图或 Common Crawl。

## 一键（可断点）

```bash
python scripts/run_all.py
python scripts/run_all.py --smoke
```

戳记在 `outputs/pipeline_stamps/`。删除某个戳记即可重跑该阶段。

## 分步

```bash
python scripts/generate_webforge.py
python scripts/generate_webforge.py --hard-only --hard-pages 320
python scripts/generate_webforge.py --hard-only --hard-pages 240 --split-name hard_train --seed0 77777
python scripts/download_benchmarks.py

python scripts/train.py --run-name webgap_sft --baseline webgap --epochs 2
python scripts/eval.py --run-name webgap_sft --ckpt outputs/runs/webgap_sft/checkpoint --split heldout --max-samples 500
python scripts/eval_hard.py --max-samples 400
python scripts/eval_public.py
python scripts/efficiency.py

python scripts/plot_results.py
python scripts/write_report.py
```

冲突页继续训练（与评测 `hard_struct` 种子不相交）：

```bash
python scripts/train.py --run-name webgap_hardmix --baseline webgap --epochs 1 \
  --max-samples 800 --ckpt outputs/runs/webgap_sft/checkpoint --split hard_train
```

改论文图：只动 `scripts/plot_results.py` 的 `style()`，原始 CSV 在 `figures/data/`。实验报告为中文：`docs/EXPERIMENTS.md` 与 `docs/zh/实验报告.md`。
